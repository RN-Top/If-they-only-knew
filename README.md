# If They Only Knew

> "If you only knew the magnificence of the 3, 6 and 9…" — attributed to Nikola Tesla (original source not yet found)

This app treats that line as a working hypothesis and tests it through every lens it can. Each claim gets a clear statement, a test anyone can rerun, a control, and a verdict: **proven**, **not proven yet**, or **unverified**.

## The lenses
| | Lens | What it tests |
|---|---|---|
| 🧷 | The Wall | Every claim pinned to one board; gold threads join the proven ones |
| Ⅰ | The Family | Every multiple of 3 reduces to 3, 6 or 9 (with proof) |
| Ⅱ | The Vortex | Doubling loops 1-2-4-8-7-5 and never touches 3, 6, 9 |
| Ⅲ | Sequence Lab | Test any arrangement (369369369, 333666999…) against random sequences |
| Ⅳ | Nine-Box Grid | The 8 magic squares hidden among 362,880 grids |
| Ⅴ | Tesla's Field | Three-phase power and the rotating magnetic field |
| Ⅵ | Harmony | 3, 6 and 9 in the harmonic series |
| Ⅶ | As Above, So Below | Earth and sky measurements against chance, in km and miles |
| Ⅷ | Triangles | Triangular numbers only reduce to 1, 3, 6 or 9 |
| Ⅸ | Spheres & Domes | 3D geodesic domes built from triangles |
| Ⅹ | Maps | Ancient sites on a spinning globe, against random points on Earth |
| Ⅺ | Calendar Map | Every day of the year on a nine-ring wheel |
| Ⅻ | Living Patterns | Animated times-table circles, the Vedic square, Pascal's triangle, the Fibonacci wheel |
| 🔎 | Search Engine | Any word, name, date or number, run through ciphers and every lens |
| ✝ | Biblical Numbers | Scripture's numbers, with sources |
| 🔢 | Numerology | Life path and expression numbers, with a century-wide control |
| ⚡ | Electricity | The numbers of electric power |

The sidebar changes the counting base. If a pattern disappears in base 12, it belongs to how we count, not to the universe.

pip install -r requirements.txt
